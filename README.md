# 🌙 RECLAIM YOUR HEART

> *"Verily, in the remembrance of Allah do hearts find rest."* (Surah Ar-Ra'd, 13:28)

Welcome to **Reclaim Your Heart**, a modern, interactive, and heart-centered application designed to help you connect with the Holy Quran and the beautiful teachings of Islam. Built with love, precision, and the latest technology, this project is a digital companion for your spiritual journey.

---

## 🕌 The Motivation: A Ramadan Gift

This project was born from the spiritual energy and reflection of the **Holy Month of Ramazan**.

Ramadan is not just about abstaining from food and drink; it is a time of reconnection, revelation, and renewal. It was in this blessed month that the Quran was first revealed. Inspired by the spirit of giving and seeking knowledge during Ramazan, I set out to build a tool that makes the wisdom of the Quran accessible, engaging, and deeply personal for everyone—whether you are a lifelong Muslim, a new revert, or a curious soul exploring the faith.

The goal was simple: **To build an interface that feels "crafted," not just "coded."** To create a space where technology meets spirituality, allowing users to explore the depths of Islamic knowledge with the help of modern AI, while keeping the experience grounded, respectful, and authentic.

---

## ✨ Key Features

### 📖 **Smart Quran Reader**
- **Beautiful Uthmani Script:** Crystal clear Arabic typography for a seamless reading experience.
- **Multi-Language Support:** Instant translations in English and Urdu.
- **Audio Recitations:** Soul-soothing recitations to help you perfect your Tajweed.
- **AI-Powered Tafseer:** Click on any Ayah to get an instant, comprehensive explanation (Tafseer), historical context (Asbab al-Nuzul), and fun facts generated by advanced AI.
- **Offline Mode:** Download Surahs and their Tafseer to read and reflect even without an internet connection.

### 🤖 **AI Companion & Guide**
- **Ask AI:** A friendly, safe, and knowledgeable AI assistant ready to answer your questions about Islam, faith, and life.
- **Personalized Learning:** Whether you're asking about the pillars of Islam or the meaning of a specific verse, the AI provides gentle, accurate, and sourced answers.

### 🏆 **Gamification & Progress**
- **Earn Rewards:** spiritual seeking shouldn't be boring! Earn points (Hasanat) for reading, learning, and quizzing.
- **Achievements:** Unlock badges like "Scholar Junior," "First Step," and "Consistent Reader" as you progress.
- **Quizzes:** Test your knowledge after every Tafseer session to reinforce what you've learned.

### 🌍 **Discover Islam**
- **Beginner Friendly:** A dedicated section for those new to the faith, covering the 5 Pillars, 6 Articles of Faith, and more.
- **Science & Islam:** Explore the miraculous scientific facts mentioned in the Quran centuries before modern discovery.

## 🛠️ Tech Stack

This project is built using a cutting-edge full-stack architecture:

- **Frontend:** React 19, TypeScript, Tailwind CSS, Framer Motion (for beautiful animations).
- **Backend:** Node.js, Express (serving as a proxy and API handler).
- **AI Integration:** Google Gemini API (Flash 2.5 & Pro models) for generating Tafseer, quizzes, and chat responses.
- **Build Tool:** Vite for lightning-fast development and optimized production builds.
- **Deployment:** Vercel-ready configuration.

## 🚀 Getting Started

Follow these steps to set up the project locally:

### 1. Clone the Repository
```bash
git clone https://github.com/ibtesaamaslam/ISLAM.git
cd ISLAM
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Configure Environment Variables
Create a `.env` file in the root directory and add your Gemini API key:
```env
GEMINI_API_KEY=your_google_gemini_api_key_here
```

### 4. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view the app in your browser.
